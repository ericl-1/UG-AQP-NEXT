# AQP analytical-Q identity

The analytical-Q mark is the canonical visual identity for Assessment Quality Platform.

- Primary garnet: `#A31515`
- Wordmark neutral: `#26313B`
- The Q and embedded analytical bars are white.
- Keep clear space around the mark equal to at least one bar width.
- Do not recolour, stretch, rotate, add a quality-check badge, or separate the bars from the Q.

The application embeds this artwork directly in `index.html` so its single-file deployment remains intact. These source SVG files are retained for documentation, future institutional packaging, and derivative assets.
